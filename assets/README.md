# Assets

All pet & accessory art is original pixel art authored on a 32×32 grid.

| Folder | Contents |
| --- | --- |
| `pets/<species>/` | `pose_frame.png` (256px), `sheet.png` contact sheet and `sheet.json` (anchors, palette, frame counts) for Puffling, Mochi Cat, Ember Fox, Clover Bun, Pebble Penguin. |
| `accessories/` | Standalone previews of every hat / glasses / scarf / jacket / backpack / toy / companion layer. |
| `environments/` | Layered parallax scenes live in `src/components/pet/Environment.tsx` (vector, so they scale to any screen). |
| `icons/` | App icon, splash and adaptive icon (generated by `scripts/generate-icons.js`). |
| `ui/`, `sounds/` | Reserved for bitmap UI chrome and audio (sounds are synthesised at runtime in `src/services/sound.ts`). |

Source of truth for the sprites is `src/engine/pets.ts` + `src/engine/accessories.ts`;
the PNGs are exported with `npm run assets` and the QA contact sheet with `npm run sheet`.
The runtime renders the same sprite data directly with `react-native-svg` (`src/engine/PixelSprite.tsx`)
so every frame stays crisp at any size and accessories can be composed per pet at runtime.
